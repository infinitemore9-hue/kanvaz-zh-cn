# simple.6：悬停取色、画布文字工具与数值滑块

日期：2026-10-28。交付标记 9.8.2-cn.simple.6，程序基础版本仍为 9.8.2。本次是本地预览构建，尚未上传 GitHub，也没有替换此前的公开发行版。

## 文字操作

- 标题栏“文字”可直接在当前视口创建文字并输入。
- 选中单个文字卡片时，在选框旁显示固定屏幕尺寸的工具条；缩放画布时控件不会随文字缩小。
- 字体预设、10–512 字号、加粗、斜体、对齐、颜色、适应文字、进入编辑均可直接操作。字体是否安装由当前系统决定，缺失时使用回退字体。
- 字号保留精确数值并配滑块。展开“位置与尺寸”，X/Y/宽/高同样有数值输入和滑块。
- X/Y 没有固定边界，因此滑块提供当前位置前后 1000 的局部范围；需要更大移动时仍可拖动或直接输入。
- 双击进入编辑；Esc 或 Ctrl+Enter 结束编辑；文字旁的六点拖动柄在编辑时也能抓住移动。
- 属性面板、设置及参考工具内的数字输入也配上滑块；已有滑块不重复添加。连续字号/位置滑动按一次操作撤销，属性框失焦不重复提交。
- 撤销/重做后，仍存在的选中卡片保留选区，文字工具条不会因此消失。

本次文字控件针对“文字卡片”。便笺、图片中的文字和导出图的文字排版未作为同一功能扩展。请用画板副本测试，旧版不能完整识别新增字体/粗细/对齐样式。

## 悬停取色

在画板静态图片上移动鼠标即可显示 HEX、RGB、HSL、Alpha 和原图像素坐标。Ctrl+Shift+C 复制当前颜色；设置里的“复制颜色格式”可选 HEX/RGB/HSL，“悬停显示图片颜色”可关闭提示。

取样读取浏览器解码后的 8 位 sRGB 原图像素，不包含软件的灰度、亮度、对比度、卡片透明度等显示效果。它不是全桌面取色器，也不是 Photoshop 文档色彩管理/CMYK/Lab 的等价实现。完全透明像素显示为透明，不能误当黑色复制。PNG 的低透明度颜色可能受到画布预乘/解预乘量化影响。

采样处理了图片适配（contain/cover）、翻转、画布缩放和屏幕像素比。拖动时隐藏提示；源图片更新后，鼠标不移动也会重新取样。提示使用 Shadow DOM，避免每次数值刷新触发全页面汉化扫描。

对生成的 Windows x64 程序执行 Electron 自动化测试：

- HEX/RGB/HSL、原图坐标、50% 缩放、DPR 2、横纵翻转、灰度预览下的原图取样、透明与半透明像素、contain 留白和 cover 裁切均通过。
- 复制快捷键按所选格式向剪贴板 API 传参已验证；测试替代了 API，未改动系统剪贴板，未验证粘贴到其他软件的端到端行为。
- 拖动隐藏、设置关闭和鼠标静止时图片刷新后的重新取样通过。
- 创建文字、输入、结束编辑、字号滑块一次撤销/重做、字体/加粗/斜体/对齐/颜色、适应文字、位置滑块、编辑状态拖动柄移动通过。
- 新增文字样式通过序列化与恢复检查；没有用系统另存对话框进行完整人工保存测试。
- 属性 X 滑块实时修改、一次撤销、失焦不重复提交，以及设置数字输入的滑块覆盖检查通过。
- 原有取消拖动、批量导入撤销、透明内容吸附、外部图片覆盖刷新等回归通过。
- 最终 validate 返回成功；缺独立 Chrome 和 MCP bridge 依赖的部分仍为 SKIP。静态检查 0 错误，5 条既有警告。
- 构建使用 Electron 44.4.3、electron-builder 26.15.3；已验证目录式 Windows x64 程序，非安装器，可执行文件未签名。
