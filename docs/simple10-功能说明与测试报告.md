# simple.10：透明排布、智能间距与参考图工作流

日期：2026-11-04。基础版本 9.8.2，非官方本地预览标记 9.8.2-cn.simple.10。本轮未推送 GitHub，也未替换线上发行版。保留原作者署名与 MIT 许可证。

## 1. 透明图按可见内容排布

多选 → 底部“排列选中对象” → 排布边界选择“可见内容边界”。设置间距，点击水平/垂直间距、等距分布或对齐按钮，画布先出现虚线边界预览，点击“确认排布”后才移动。取消或 Escape 清除预览，改变选中对象、图片位置或尺寸后，旧预览不能继续应用。确认排布记为一步撤销。

“不透明度阈值”范围 1–255，默认 16。只把 alpha 大于或等于阈值的像素计入边界；提高阈值可忽略较淡阴影。它不是颜色亮度阈值。阈值设得过高可能忽略半透明产品细节，因此要看预览再确认。完全没有达到阈值的图片跳过，锁定/隐藏对象不移动。可见内容模式中锁定对象不参与计算；原有整张图片边界的对齐规则保持原样。

间距仍默认 24 个画布像素，允许 0；不改变图片尺寸，不裁切或重写图片，支持卡片的包含/覆盖显示及水平/垂直翻转。指定间距时，透明画布矩形允许重叠，以让可见内容达到目标间距。非图片对象使用其矩形边界。

边界检测最长边以最多 4096 像素扫描，超大原图的边界是采样近似，并不承诺逐像素精确。包含模式中图片四周的显示留白也会被正确投影。相同扫描阈值、图像来源的结果缓存；源图更新后重新计算。此阈值仅用于排布预览，原有拖动吸附的可见边界仍沿用此前规则。

## 2. 智能间距提示与等距吸附

拖动时显示附近左/右/上/下对象之间的距离，数值单位是画布像素。与同一行或列相邻两个参考对象的间距接近时，可以吸附到相同间距；也支持在两个对象之间居中插入。已有边缘、中心对齐优先，避免和等距候选互相争抢。

沿用边缘吸附的屏幕距离阈值和松脱范围。Shift 临时解除吸附，松开恢复；结束拖动清除参考线。网格吸附开启时不同时做这些边缘/间距吸附。排布面板中的“显示间距并吸附到等距位置”可关闭本项。

这是对相邻行列的等距辅助，不是 Photoshop/Illustrator 全套智能参考线实现，也不是在复杂交错图片间搜索所有可能的间距组合。

## 3. 文字样式预设

选中文字 → 文字工具条“位置与尺寸” → “文字样式预设”。提供标题、说明、参数三种内置样式；内置文字颜色随主题使用默认颜色。可以输入名称保存当前样式，最多 20 个自定义预设；同名自定义预设再次保存会更新。

保存字体、字号、加粗、斜体、颜色、对齐方式和文字框尺寸模式，不保存文字内容、坐标和固定宽高。应用预设计为一步撤销，锁定文字不能套用。自定义预设保存在当前配置中，重启可继续使用。系统未安装指定字体时会使用字体回退，不保证不同设备字形完全相同。

## 4. 两张图片对比

多选恰好两张静态图片 → 排布面板“对比两张图片”。支持并排、叠加、A/B 切换，统一缩放和平移；缩放、不透明度都有滑块和精确数字输入，提供重置与 Escape 关闭。

默认按两张原图的相对像素尺寸，用同一缩放比例显示。勾选“匹配显示尺寸”后，各自等比适应显示区域；不会拉伸长宽比。叠加模式可调 B 图不透明度。面板使用打开时的原图快照，不改变画布物体坐标、尺寸或图片文件；不显示卡片预览滤镜，不是 Photoshop ICC 色彩管理对比。外部文件更新后需重新打开对比，以使用新快照。本轮不支持视频对比。

## 5. 可保存的命名视图书签

标题栏“视图”打开书签面板。每张画板有 1–9 九个位置，可命名、保存、跳转和删除；名称最多 80 字符。原有 Ctrl+1…9 保存、1…9 跳转快捷键继续使用。

书签随画板写入 .kanvaz 文件，包含缩放和画布位置。新画板不会继承其他画板的书签。打开没有书签的旧文件时正常使用空书签。书签不是截图，也不改变图层内容。

## 6. 最近取色与颜色收藏

标题栏“颜色”打开面板。复制取色框颜色成功后加入最近记录；也可点击“保存最近取色”。鼠标只是在图片上移动时不连续保存，避免刷满列表和反复写盘。

最近颜色最多 20 个，收藏最多 30 个；相同 HEX 与 alpha 合并为一条最近记录。可输入名称后收藏，取消收藏，复制 HEX/RGB，以及单独清空最近记录。保留取色时的来源图片名称、像素坐标、RGB/HSL、alpha 信息；这是当时的颜色快照，不会跟随源图片改色。清空最近记录不清空收藏。最近记录和收藏保存在当前配置中，重启保留。

原有取色仍是浏览器解码后的 8 位 sRGB 原图取样，不是整个桌面的屏幕取色。HEX 为六位 RGB；半透明颜色复制 RGB 时提供 rgba，面板另外显示 alpha。
