# simple.7：轻量取色提示与移动反馈

日期：2026-10-28。交付标记 9.8.2-cn.simple.7，基础版本 9.8.2。本轮为本地预览构建，没有推送或修改 GitHub 发行版。

## 取色不再挡住鼠标附近

默认显示改成右下角的精简小条，只保留色块、HEX 和小按钮。普通颜色状态下测试尺寸小于 190×42 CSS 像素。详细 RGB/HSL、透明度、像素坐标默认折叠；点“⋯”或 F7 展开，再按一次收起。

小条的六点按钮可以直接拖动，随后成为应用内的独立浮动框，位置通过现有设置系统保存。这不是额外的系统窗口，也不覆盖其他软件。

完整界面 → 设置 → 画布与输入：
- 取色框位置：固定右下角、跟随鼠标、独立浮动框。
- 取色框内容：精简色块与 HEX，或完整数据。
- 取色显示方式：悬停显示，或按住 Ctrl 时显示。
- 取色框不透明度：45%–100%，默认 92%。数值输入配滑块。
- 取色出现延迟：0–1000 毫秒，默认 150 毫秒。

F6 开关取色框，F7 展开/收起数据；在文本/数字输入期间不抢占这些按键。点击色号或 Ctrl+Shift+C 按所选格式复制。独立浮动/停靠模式离开图片后保留最后一次颜色，方便操作框上的按钮；切换画板使来源卡片不存在时清除读数。跟随鼠标模式保持鼠标穿透。

## 同时加强的操作

- 移动物体时按住 Shift，临时绕过边缘和网格吸附；松开 Shift 后恢复。按下或松开 Shift 不需要再移动鼠标即可生效。缩放操作仍保留原有 Shift 含义，本次只调整移动过程。
- 当前吸附目标显示细轮廓；透明图按可见内容的轮廓提示，避免把透明留白当成目标边界。结束或取消拖动时清除提示。
- 文字工具条在移动物体时隐藏，松开后恢复；提供贴近选框、固定顶部、隐藏三种位置设置。
- 更换选中的文字时自动收起位置尺寸区域，减少一次展开后持续遮挡。

未增加等间距自动分布或文字样式预设，未宣称与 Photoshop/Illustrator 的完整智能参考线行为相同。

## 实际测试

对本次 Windows x64 构建运行 Electron 自动化：默认小条尺寸与位置、跟随模式鼠标穿透、60% 不透明度、点击展开、拖动位置写入设置、F6/F7、按住 Ctrl 显示/松开隐藏、出现延迟均通过。

移动时 Shift 解除锁定、恢复吸附、目标轮廓清除、网格吸附绕过、文字工具条拖动隐藏、固定顶部/关闭均通过。此前原图颜色映射、文字控件、连续滑块撤销、透明内容吸附、强吸附和原图字节/像素检查的回归通过。

项目 validate 成功；缺独立 Chrome 和 MCP bridge 依赖的部分依旧为 SKIP。静态检查 0 错误、5 条既有警告。窗口系统版本 10.0.26100，Electron 44.4.3，electron-builder 26.15.3。交付是未签名的 Windows x64 目录式便携 ZIP，不是安装器。

复制格式测试使用了剪贴板 API 替代，不改动系统剪贴板；没有验证跨软件粘贴。取样仍为静态图片浏览器解码后的 8 位 sRGB 原图，不包含预览滤镜，不是桌面取色或 Photoshop 色彩管理。未完成全平台、全格式和大规模超高清素材性能测试。
