# Kanvaz 中文版 simple.11：功能说明与测试

日期：2026-11-10。非官方本地预览版本 9.8.2-cn.simple.11；基于 Kanvaz 9.8.2，保留原作者及 MIT 许可。本轮未推送 GitHub。

## 启动与入口
完整解压 Windows-x64.zip，在新文件夹运行“Kanvaz 中文版.exe”。这是 Windows x64 目录式便携版，必须保留同目录文件；不是安装器，也不是单文件程序。使用前保存旧版中的重要画板，手动关闭旧版。
标题栏“检查”打开图片与恢复面板；再次点击或按 Esc 收起。

## 新增功能
- 透明区域背景：深色、中灰、浅色棋盘格或纯中灰；大小 4–64 像素，数值和滑块联动，可始终显示或沿用悬停/选中显示。
- 颜色对照：选中一张静态图片后进入。临时中灰背景，关闭图片显示滤镜与不透明度效果，按原图像素比例居中；退出恢复进入前的画布位置与缩放。沿用画板缩放上限，因此极端尺寸不保证精确 1:1。不会改写原始图片、卡片参数或撤销历史。对照中的主动编辑/保存仍属于正常画板操作。
- 原图取色：明确 sRGB 取样不包含显示调整，详细取色面板提示“显示效果已调整”。检查面板可重置图片亮度、对比度、饱和度、不透明度；一步撤销，保留翻转与尺寸。
- 源图片状态：选中图片可查看状态、刷新、重新关联；完整批量管理继续位于“参考图工具”。源文件丢失/解码失败时保留最后成功画面；有效文件恢复后继续同步。自动同步沿用 PNG/JPEG/BMP/WebP/GIF、每轮最多 1000 路径及单文件 128 MiB 限制。
- 恢复与备份：自动恢复文件改为串行临时写入后替换；额外保留最近 5 份历史快照，自动历史快照间隔至少 5 分钟，手动备份可立即创建。启动恢复继续可用。
- 备份预览展示画板名称和对象数量，并非缩略图预览。恢复前必须成功备份当前工作，否则不替换画板；恢复后清除原保存路径，后续保存需要另存，避免覆盖原文件。备份属于当前用户配置，不随便携 ZIP 携带。

## 验证范围
- 实际 Electron Windows 程序：背景设置/滑块、临时滤镜与不透明度覆盖、卡片与源数据保持、退出精确恢复视图、重置一步撤销。
- 实际磁盘与 IPC：备份列表/内容预览/恢复、恢复前当前工作保留、恢复后保存路径为空。
- 实际临时源文件：删除、无效内容写入、恢复有效 PNG；旧像素在失败期间保留，恢复后更新。未在本轮操作 Photoshop 实际保存。
- 备份存储单测：并发写入顺序、历史上限、无效数据/路径拒绝、重建实例后间隔、写入失败、清理当前自动保存仍保留历史。
- 回归：simple.10 排布、等距吸附、文字预设、书签、两图对比、颜色收藏及重启恢复；原作者署名、许可和关闭上游自动更新。
- 静态验证：0 错误、5 项既有警告；独立 Chrome/Chromium 与 MCP 依赖缺失相关检查跳过，不能视作通过。
- 首次源状态等待及首次旧文字预设重启 UI 等待曾超时，隔离重跑通过；日志保留在开发记录。未据此宣称所有环境均稳定。

## 色彩与其他限制
本轮没有增加 ICC 转换、HDR 校准或修改原图颜色，也没有强制 Chromium 使用 sRGB 显示配置。sRGB 指原图取色输出空间；界面颜色对照不是显示器校准或印刷软打样。用户截图的少量对应区域数值接近不能证明所有图片和显示器都无色差。
便携程序无数字签名。此前版本的公开发行版不随本轮自动更新。本轮不覆盖用户运行中的旧程序，也不修改其当前画板。
