# Kanvaz simple.5 使用说明与测试报告

构建日期：2026-10-23。基于上游 v9.8.2 的非官方简体中文修改版；本次交付标记 simple.5，程序内部版本仍为 9.8.2。适用于 Windows x64；可执行文件未签名。

## 启动
关闭旧版，把 Windows-x64-portable.zip 完整解压到新的文件夹，运行“Kanvaz 中文版.exe”。请保留同目录所有文件。这是目录式便携包，并非单文件程序或安装器。替换前建议另存重要画板备份。

## 本次完成
- 拖动卡片时按 Esc，恢复拖动前的位置并结束拖动；多选成员一起恢复。取消不新增移动历史。
- 收到窗口失焦事件时取消当前拖动并恢复位置，防止鼠标状态遗留。
- 多文件读取完成后一起加入画板；创建和自动排列合并为一次撤销。重做恢复整批图片及排列位置。加载期间的其他编辑不被吞并到导入历史。
- 透明图片框选与可见内容吸附使用同一边界范围。设置“按图片可见内容吸附与框选”默认开启；关闭后使用完整图片矩形。
- 源图片管理按实际读取、解码、替换结果显示“等待文件写入完成”“正在更新图片”“图片已更新”“图片更新失败，正在重试”，并显示最近成功更新时间。失败保留旧画面，后续轮询继续尝试。更新时间只代表当前运行期间成功刷新，不作为画板数据保存。
- 保留缺失文件、暂停同步、超限状态，以及手动刷新入口；新增界面文字支持中英文切换。

## 实际验证
对新构建的 Windows 程序进行 Electron 自动化交互测试：
- 单张拖动按 Esc 后回到原位，之后移动鼠标不继续拖动；多选拖动取消后所有可移动成员回到原位。
- 模拟窗口 blur 事件能取消并恢复拖动；尚未实际验证 Alt+Tab、多显示器切换等系统场景。
- 框选仅经过透明留白不会选择图片；切换到完整图片边界模式可选择。
- 一张原有卡片加三张导入图片，撤销一次从四张回到一张；重做恢复四张及排布位置。
- 图片加载期间创建的另一张便笺，在撤销批量导入后保留；加载期间切换画板不会把本批图片添加到另一个画板。
- 文件直接覆盖、临时文件原子替换、删除后恢复、写入损坏数据后恢复均验证；刷新保持显示位置和尺寸，其他图片不变。
- 验证源文件损坏时的错误状态、成功刷新时间及管理界面中文提示。
- 透明内容吸附、翻转投影、裁切、多选相对间距、远处对象排除、零间距吸附、50% 缩放、PNG 原始字节、原图像素检查回归通过。
- 项目 validate 返回成功；其中依赖独立 Chrome 和 MCP bridge 插件依赖的检查显示 SKIP，不能视作已执行通过。独立 Electron 交互测试另行运行，见记录。静态检查为 0 错误、5 条既有警告。

## 范围与限制
- 本次未修改工具面板的模态方式，未增加临时关闭吸附按键，也未完成工具按钮动态数量标注；这些仍是后续优化项。
- 可见内容指 alpha 通道阈值计算的联合矩形，不是逐像素命中，也不会拆分一张 PNG 中的多个物件。动画 GIF 的逐帧透明范围未验证。大于 4096 像素的图像使用采样边界，存在采样误差。
- 这次没有使用用户截图里的原始产品 PNG，也未通过真实 Photoshop 保存流程验证；覆盖测试模拟了直接写入和替换文件。不能宣称全面兼容 Photoshop、Illustrator 或 PureRef。
- 未完成大量超高清透明图片、所有格式、所有 Windows 版本和多显示器的全面验证。
