# simple.8：临时预览、快速排布与文字自适应

日期：2026-10-28。基础版本 9.8.2，非官方本地预览标记 9.8.2-cn.simple.8。本轮未推送 GitHub，也未更改线上发行版。保留原作者与 MIT 许可证。

## 怎么使用

### 临时查看图片

将鼠标放在静态图片上，按住空格约 350 毫秒，显示应用内的大图预览；松开空格立即关闭。预览读取卡片的原图数据，按窗口空间等比显示，不改变画布缩放、位置或选中对象。不是固定 100% 原像素显示，不提升原图分辨率。

原有“空格＋鼠标左键拖动”继续用于平移：按下鼠标即取消临时预览。滚轮、窗口失去焦点、来源卡片消失也会关闭预览。文字输入期间不触发。可在“完整界面 → 设置 → 画布与输入 → 图片上按住空格临时预览”关闭。

### 多选后快速排布

选择至少两项，窗口底部出现收起的“排列选中对象”。展开后有六种边缘/中心对齐、水平/垂直等距分布，以及指定间距的水平/垂直排列。取消多选后面板隐藏，移动卡片时也隐藏。

- “等距分布”需要至少三个未锁定对象，保持首尾对象位置，在它们之间均分间距；空间不足时可能产生重叠。
- “应用水平/垂直间距”需要至少两个未锁定对象。按当前相应坐标排序，固定第一个对象，逐个设置间距；默认 24 个画布像素，可以为 0。输入框带滑块，支持 0–4096。
- 指定间距不修改物体尺寸、不改变另一轴坐标。锁定与隐藏对象不参与指定间距排列。对齐操作沿用原有规则，锁定对象可以作为对齐参考，但自身不移动。
- 每次点击排布按钮记为一步撤销。面板出现时，短暂的撤销等通知显示在面板上方，避免挡住按钮。

排布以卡片矩形为准，不是透明图中可见内容之间的距离；旋转卡片也不计算旋转后的视觉边界。原有透明内容吸附功能仍保持独立。

### 文字框自动适应

选择一张文字卡片，在文字工具条展开“位置与尺寸”，选择“文字框尺寸模式”：

- 固定尺寸：保留现有行为。旧画板和新文字默认使用此模式。
- 固定宽度，自动高度：保留宽度，随文字、字号和宽度变化重新计算高度；删除文字后也会收缩。
- 自动宽度与高度：随文字和字体变化计算宽高。超过宽度上限后换行。

位置不因自适应改变。模式写入画板记录，支持撤销和重新载入。宽高沿用应用最小 80 像素限制；自动计算上限为宽 4096、高 8192，特别长的文字可能超过显示范围。需要自由拖动宽高时切回固定尺寸。原有“适应文字”按钮仍可使用。

### 方向键精细移动

原版已有：方向键移动 1 个画布像素，Shift＋方向键移动 10 个画布像素，与当前画布缩放无关，多选也可用。连续一组移动合并为一次撤销。

这次补强：编辑文字、可编辑内容、数字输入、下拉框、滑块、按钮以及弹窗期间，方向键不移动画布对象；Ctrl/Alt 组合不误入普通移动。锁定或隐藏对象不移动。

## 测试范围与结果

在本机 Windows（系统版本 10.0.26100）、Electron 44.4.3、electron-builder 26.15.3 的 Windows x64 目录式构建上运行真实 Electron 自动化。

新测试覆盖：空格预览/松开恢复、视图与选择不变、空格拖动平移、关闭预览设置、多选面板折叠、24/0 像素间距、尺寸与另一轴不变、一步撤销、垂直排列、水平等距、对齐、锁定排除、1/10 像素多选移动、50% 缩放移动、输入与弹窗保护、文字模式控件、字号/内容/宽度变化、文字收缩、序列化重新载入、模式撤销、中英文标签，以及通知不拦截排布面板点击。

保留 simple.7 的小条取色框、透明度、按 Ctrl 显示、拖动位置、Shift 解除吸附和文字工具条移动隐藏。回归测试记录与构建、validate 日志随包交付，以日志中的 PASS/SKIP 为准。

本次新功能集成测试与上述回归均通过。validate 成功；静态检查为 0 错误、5 条既有警告。缺独立 Chrome/Chromium 和 MCP bridge 依赖的项目检查为 SKIP，不计为通过。预览失焦会主动关闭，因此依赖焦点的 Electron 窗口测试最终按顺序运行，避免多个测试窗口互相干扰。还验证了真实应用确认对话框中的方向键保护，以及专注参考视图中隐藏新面板。

交付形式是未签名的 Windows x64 目录式便携 ZIP。全部解压后运行“Kanvaz 中文版.exe”，保留同目录其他文件。未验证其他 Windows 版本、macOS、Linux、大量超高清素材性能、全部字体和输入法。本轮不宣称 Photoshop/Illustrator 完整兼容，也没有增加视频临时预览。
